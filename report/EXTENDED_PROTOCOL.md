# Протокол завершения исходной постановки

Зафиксирован 10 ноября 2026 года после прямого запроса завершить проект и проверить пользу дополнительных данных. Прежние финальные выборки R4–R6 остаются закрытыми для настройки. Новые результаты добавляются отдельными блоками, без подмены прежних отрицательных результатов.

## R7. CODE и расширение городских данных

Из актуального списка файлов OSF скачиваются CODE core за 2018, 2019 и 2022 годы. Вместе с имеющимися 2020–2021 они номинально охватывают пять календарных лет. Основная панель — прежние 17 городов; фактическое наличие и покрытие фиксируются, пропуски не дорисовываются. По последующей проверке у трёх городов есть пропуски целых месяцев; правило исключения рядов с неполной историей не менялось.

Прямые городские выгрузки расширяются до Chicago, NYC, San Francisco и Seattle за 2019–2025 и январь–сентябрь 2026 года. У NYC текущий набор квартальный и заканчивается сентябрём. Для сопоставимости общий конец — 1 октября 2026, исключительно. Данные 2026 не называются полным годом. Они остаются отдельными источниками, не «обновлённым CODE».

Сохраняются минимальные поля идентификатора и времени, без координат и сведений о людях. Каждая выгрузка имеет URL, время получения, проверку числа строк до/после и SHA-256. Городские строки дедуплицируются по идентификатору дела/отчёта; при нескольких временах выбирается самое раннее наблюдаемое время. Для CODE сохраняется единица записи правонарушения и uid, без выдуманного объединения разных правонарушений в дела.

Семейство данных выбирается до просмотра scores. Для применения модели используется 730 суток префикса и 12 завершённых стадий по 90 суток; начало выбирается механически по доступному календарному интервалу, без поиска тревожного периода. В CODE это один ранний блок 2018–2022; для свежих городов — последний полный 1810-суточный блок, заканчивающийся 1 октября 2026. Поздний блок 2019–2023 городов также проверяется как чувствительность к периоду, с явной возможностью перекрытия, без объявления его независимой выборкой.

Фон каждого блока обучается только по его префиксу. Проверяются исходные замороженные модели R4 и новый вариант R9. Неизвестные n не заменяются оценками модели как истинными метками. Сохраняются оценки, тревоги, доли неудач, временная точность, покрытие и отклонение интенсивностей/признаков от обучения. Нет accuracy, TPR или «ложных тревог» относительно неизвестной городской критичности. Эмпирическое применение модели — выполненная проверка переноса, но не валидация истинной критичности.

## R8. Настоящие размеры кластеров

100 000 полных генеалогических деревьев на каждый из n=0,0.2,0.4,0.6,0.75,0.85,0.92,0.97. Потомство Poisson(n), задержки Exp(β), β=1/сутки. Размер включает корень и всех потомков, без обрезания временным окном. Родители и поколения известны из имитации. Исследуются средний размер, дисперсия, хвостовые доли, квантиль и длительность. Проверяется согласие E[S]=1/(1−n), Var(S)=n/(1−n)^3. Эти показатели дополняют P1; истинная генеалогия не подаётся детектору реальных данных.

## R9. Один расширенный нейросетевой вариант

Дополнительные строки преступлений не являются размеченными примерами критичности. Поэтому расширяется обучение на симуляциях с известными параметрами.

- Обучение: только прежние train-части R4/R5/R6 (всего 5 850 потоков) плюс 1 950 новых, всего 7 800. Старые validation/calibration/test в обучение не включаются.
- Новые независимые валидация 1 950, калибровка 3 900, финальный тест 3 900 потоков. Все 13 семейств сохранены. Новые семена не пересекаются с R4–R6.
- Наблюдаемая модель: прежние причинные 64 признака для окон 90 и 360 суток объединяются в 128. Истинный n не входит во вход.
- Сеть 128→64→32→3, ReLU, dropout 0.1. Выходы: logits состояния и предупреждения, вспомогательная оценка текущего n через sigmoid.
- AdamW, lr=0.001, weight decay=0.001. Потеря: 0.5×взвешенная BCE состояния +0.5×взвешенная BCE предупреждения +4×MSE текущего n. Нормировка и веса классов — только по обучению.
- Не более 200 эпох. Проверка валидационной потери каждые 10 эпох и в конце; выбирается минимум. Seed 101,113,127; первичные модели — заранее заданное среднее всех трёх, отдельно для двух задач.
- Диапазон симуляционных интенсивностей остаётся 0.2–50/сутки. Массовая городская интенсивность может выходить за диапазон; это отмечается как ограничение переноса, без ложного заявления адаптации по масштабу.
- Перед генерацией нового финального теста замораживаются все веса и пороги. Основная калибровка: цель 5% траекторных ложных тревог, совместное доверие 95% по всем 12 новым оценкам и активным семействам. Номинальная семейная калибровка — заранее объявленная чувствительность.
- Замороженные первичные R4 дополнительно оцениваются на том же новом тесте с прежними порогами. Их исходный тест и результаты сохраняются.

Сохраняются все seed, интервалы и отрицательные результаты. Вспомогательная голова n — вторичный результат, не способ выбрать победителя по тесту. Более высокая AUC не считается достаточным результатом, если полнота при заданном контроле тревог остаётся малой. После R9 новый перебор по его финальному тесту не проводится.

## Завершение и сдача

После проверки R7–R9 обновляются основной Markdown-отчёт, реестр доказательств, рисунки, выступление и таблица выполнения исходных условий. Передача комплекта не требует положительного результата детектора: требуется честно измеренное качество, завершённые проверки и воспроизводимые выводы. Личные сведения автора и фактическая репетиция остаются действиями пользователя и не отмечаются выполненными автоматически.
