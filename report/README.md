# Материалы для завершения проекта и защиты

Тема: **«Исследование критических режимов самовозбуждающихся случайных процессов и методов их раннего обнаружения»**.

Дата итогового комплекта — 10 ноября 2026 года. Защита ожидается в начале декабря. Исследовательские и программные задачи завершены досрочно; оставшееся время можно использовать для изучения материала и репетиции. Все текстовые материалы оформлены в Markdown.

| Файл | Назначение | Состояние |
|---|---|---|
| [REPORT.md](REPORT.md) | Единый текст исследования: постановка, модель, методы, результаты и ограничения | Итоговая редакция |
| [PLAN.md](PLAN.md) | Календарный план, границы последнего эксперимента и критерии завершения | Рабочий план до защиты |
| [EVIDENCE.md](EVIDENCE.md) | Источники чисел, соответствие утверждений протоколам, происхождение рисунков | Реестр проверенных результатов |

Исходные экспериментальные отчёты остаются в `results/`. Они нужны для проверки и воспроизведения, но не заменяют единый текст: различия между пилотными, окончательными и диагностическими проверками должны сохраняться.

Обновление рисунков из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts/prepare_report_assets.py
.\.venv\Scripts\python.exe scripts/verify_report.py
```

Проверка отчёта контролирует локальные ссылки, структуру таблиц, копии рисунков, ключевые ячейки результатов и неизменность замороженных итоговых метрик. Она не заменяет статистические проверки экспериментов.

Закрыты прежние пробелы: полные каскады R8, применение замороженных сетей к CODE и свежим данным R7, расширенное обучение R9 и итоговый отчёт. На строгом новом тесте R9 — 5 чистых предупреждений из 600, на номинальном — 27/600. Это завершённое исследование с низким качеством предупреждения, а не готовая система прогноза критических переходов. Новая настройка по финальным выборкам не проводится.
