Полные прежние Монте-Карло эксперименты R1–R5 заново не генерировались. Проверка хешей подтверждает неизменность, но не выдаётся за новый полный запуск их независимых проверок. Новые нейросетевые сравнения R6 — отдельный эксперимент, без замены первичных моделей R4.

Проверка файлов и воспроизводимости не доказывает качество предупреждения. У R6 — уменьшение MAE ценой задержки и широкие полосы; в последнем R9 — 5 чистых предупреждений из 600 при строгой калибровке. При номинальной калибровке — 27/600. Программные задачи выполнены, практически надёжное предупреждение не получено.

Итоговая редакция сверена с результатами. Личная репетиция не выполняется автоматически; сведения об авторе и группе можно добавить по необходимости. После изменения Markdown следует повторить `verify_report.py`. Выходы float32 сети R7/R9 проверяются с допуском округления до 2×10⁻⁷ при разных потоках BLAS, но решения о срабатывании должны совпадать точно.
